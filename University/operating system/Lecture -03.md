
## **Topic 1: Operating System Services**

An Operating System (OS) provides an environment for the execution of programs and provides services to both the programs and the users.

You can think of these services in **two main sets**:

### **Set 1: Services Helpful to the User**

These services make it easier for people to use the computer.

- **User Interface (UI):** Every OS has a way for the user to interact with it, whether it is a Command-Line (CLI), a Graphical User Interface (GUI), or a Touch-screen.
    
- **Program Execution:** The OS must be able to load a program into memory, run it, and handle its ending (either normally or if it crashes).
    
- **I/O Operations:** Since a running program cannot talk to hardware directly, the OS handles requests for Input/Output, like printing or reading from a disk.
    
- **File-system Manipulation:** This involves the ability to read, write, create, delete, and search for files, as well as managing permissions.
    
- **Communications:** The OS allows different processes to exchange information, either on the same computer or over a network.
    
- **Error Detection:** The OS constantly monitors the hardware (CPU, memory) and user programs to detect and fix errors to keep things consistent.
    

---

### **Set 2: Services for System Efficiency**

These services ensure the computer itself runs smoothly by sharing resources.

- **Resource Allocation:** When multiple users or tasks run at the same time, the OS decides who gets to use the CPU cycles, main memory, and file storage.
    
- **Logging:** The OS keeps track of which users are using which resources and for how long.
    
- **Protection and Security:** The OS ensures that all access to system resources is controlled (protection) and defends the system against outsiders through user authentication (security).
