**Complete Command List (LAB 1 – LAB 5)**

**LAB 1 Commands**

1. uname -r : Shows the kernel version.  
2. uname -m : Shows the machine architecture.  
3. pwd : Prints the current working directory.  
4. ls : Prints the contents of a directory.  
5. ls -a : Displays all files and directories, including hidden ones.  
6. mkdir : Creates new, empty directories.  
7. cd : Changes the current directory.  
8. touch : Creates an empty (zero byte) new file.


**LAB 2 Commands**

9. cat : Prints the contents of a file to the screen.  
10. cat > filename : Creates a file.  
11. cat >> filename : Appends details to an existing file.  
12. cat file1 file2 > file3 : Concatenates multiple files.  
13. cp : Copies files and directories.  
14. mv : Moves or renames directories and files.  
15. rm : Removes files or directories.  
16. rm * : Deletes all files.  
17. rm -r : Removes everything in a folder.  
18. rmdir : Removes a directory.  
19. rmdir -p : Deletes a directory and its subdirectories/sub-folders.

**LAB 3 Commands**

20. uname -n : Tells the machine name in the network.  
21. cal : Displays this month's calendar.  
22. cal -3 : Displays the previous, current, and next month.  
23. cal -s : Displays the current month starting from Sunday.  
24. cal -m : Displays the current month starting from Monday.  
25. uptime : Shows the current uptime.  
26. whoami : Shows who you are logged in as.  
27. date : Shows the current system date.  
28. date +%m : Displays the month only.  
29. date +%h%m : Displays the month name and month.  
30. date +%h : Displays the month name.  
31. date +%H : Displays the time in hours.  
32. date +%M : Displays the time in minutes.  
33. date +%r : Displays the time in AM or PM.  
34. date +%d : Displays the date of the month.  
35. who : Displays login details.  
36. who am i : Displays the login user details.  
37. logname : Displays the login ID.  
38. history : Shows all commands used in the past for the current terminal session.  
39. clear : Clears the screen.  
40. bc : Calculates values.

**LAB 4 Commands**

41. man : Shows the manual pages of a command.  
42. --help : Shows ways the command can be used (e.g., cd --help).  
43. wc : Shows the number of words, lines, and bytes.  
44. wc -c : Displays the number of characters in a file.  
45. wc -l : Displays the number of lines.  
46. nl : Displays the number of lines with numbers.  
47. nl -i5 : Increments the line number by 5.  
48. sort : Sorts the contents of a file alphabetically.  
49. sort -r : Reverses and sorts the content of a file.  
50. sort -u : Sorts and removes duplicates.  
51. sort -k : Sorts by a particular field.  
52. head : Displays the first 10 lines by default.  
53. head -6c : Displays the first 6 characters.  
54. head -5 : Displays 5 lines.  
55. tail : Displays the last 10 lines.  
56. cut : Extracts a column or columns of information from a file.  
57. cut -c : Specifies the column to be extracted.  
58. cut -d, -f : Specifies a delimiter (-d) and extracts specific fields (-f).  
59. paste : Merges files together.

**LAB 5 Commands**

60. grep : Searches a file for a particular pattern of characters.  
61. grep -i : Enables a case-insensitive search.  
62. grep -c : Finds the number of lines that match the string.  
63. grep -o : Displays only the matched string.  
64. grep -v : Displays lines that do not match the specified pattern.  
65. chmod : Changes the permissions of a file or directory.
