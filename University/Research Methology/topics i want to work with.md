## Key Findings Across Research Papers

### Productivity Impact:

- **GitHub Research (2024-2025):** 55% faster task completion with Copilot
- **Perception Gap:** Developers feel 20% faster but are actually 19% slower overall (METR Study)
- **Individual Task Level:** 20-45% speed improvements observed

### Code Quality Insights:

- **GitHub 2024 Study:** Readability +3.62%, Reliability +2.94%, Maintainability +2.47%, Conciseness +4.16%
- **Code Churn Concern:** 91% longer review times, 98% more pull requests generated
- **Security Risk:** 29-40% of generated code contains potential security vulnerabilities

### Maintainability & Technical Debt:

- AI code more prone to unused constructs and hardcoded debugging
- Increased code churn (doubled from pre-AI baseline)
- Higher proportion of added/copy-pasted code vs. updated/deleted code
