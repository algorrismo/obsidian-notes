# This is the opportunity

Instead of asking:

> "Does GitHub Copilot improve productivity?"

(which has already been studied)

you could ask:

> **"How do modern AI coding assistants differ in terms of developer productivity, code quality, and maintainability under identical programming tasks?"**

That is a stronger and more current research question.

# One thing to think about before committing

Your biggest design decision is **which AI assistants you'll compare**.

For example:

- GitHub Copilot
    
- ChatGPT
    
- Cursor
    
- Gemini Code Assist
    
- Claude Code
    
- Amazon Q Developer
    

Including five or six tools makes the study more comprehensive, but it also increases the amount of work. For a university project, comparing **3–4 widely used assistants** is often a good balance between depth and feasibility.
