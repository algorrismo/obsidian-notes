### Homework 1

**Topic:** AI-Generated Code: Effects on Code Quality and Maintainability

**Research questions I hope to answer:**

1. Is code written by AI tools (like GitHub Copilot, ChatGPT, or Claude) actually as good as code written by human programmers?
**2**. Does AI-generated code have more bugs or weird logic than human-written code?
2. When a project uses a lot of AI-generated code, does it get harder to maintain, fix, or update later?
3. Do programmers actually understand the AI's code well enough to debug it months later, or do they just copy-paste it without really knowing what it does?

**Main objective:**  
To find out how AI-generated code affects the overall quality and long-term maintainability of software projects.

**Sub-objectives:**

- To compare basic quality measures (like number of bugs, how complicated the code is, how readable it is) between AI-written code and human-written code.
- To check how easy or hard it is for developers to maintain, fix, or add new features to AI-generated code over time.
- To find common problems or "technical debt" that AI-generated code might create.
- To see how much programmers actually trust and understand the AI code they use.

**Relevance to theory and practice:**  
This matters cuz everyone's using AI to code faster now but nobody really knows if its actually helping or just making more work later. So this could help fill that gap since its still pretty new and not much research exists yet.
