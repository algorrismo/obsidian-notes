# Markdown Formatting

Use clean Markdown that is optimized for Obsidian.

Use:

- # Heading
    
- ## Subheading
    
- ### Topic
    
- Bullet lists
    
- Numbered lists
    
- Tables
    
- Code blocks
    
- Mermaid diagrams (when appropriate)
    
- Internal links (`[[Topic Name]]`) where useful
    
- Tags (e.g., `#exam`, `#definition`, `#important`)
    
- Horizontal separators (`---`)
    

Use Obsidian callouts such as:

```md
> [!IMPORTANT]

> [!NOTE]

> [!TIP]

> [!WARNING]

> [!QUESTION]

> [!SUMMARY]

> [!EXAM]

> [!INTERVIEW]
```
